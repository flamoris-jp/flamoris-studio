# Contributing to FLAMORIS Studio

Thank you for your interest in FLAMORIS Studio.

Studio is the creative control center for FLAMORIS. Contributions should preserve clear authority boundaries between Studio, MCP services, runtime managers, Studio Client, and production applications.

## Before contributing

For small fixes, feel free to open a pull request directly.

For new architecture, MCP contracts, job/asset behavior, new prompt editors, persistence, or cross-repository integration, please open an Issue first.

Before implementation, read:

- `README.md`
- `AGENTS.md`
- `SECURITY.md`
- the relevant design/Issue
- the public contracts of related FLAMORIS repositories

## Pull requests

Please:

- keep changes focused;
- include/update tests where practical;
- document externally visible behavior;
- avoid unrelated refactors;
- preserve authority boundaries;
- avoid unnecessary dependencies;
- use small, meaningful commits;
- explain security/privacy implications for file, media, prompt, or remote-provider changes.

AI-assisted contributions are welcome. Contributors remain responsible for reviewing, testing, licensing, and understanding submitted changes.

## Licensing

Unless explicitly stated otherwise, code contributions are submitted under Apache License 2.0.

Do not add third-party code, models, datasets, prompts, fonts, media, generated assets, or other material unless applicable licenses and redistribution terms are compatible and documented.

## Support

FLAMORIS does not provide guaranteed individual support. Use repository documentation, Issues, tests, logs, and source code as primary references. AI-assisted self-support is encouraged.

# FLAMORIS Studio へのコントリビューション

小さな修正は直接Pull Requestでも構いません。

アーキテクチャ、MCP境界、job/asset、Prompt Editor、永続化、複数Repositoryにまたがる変更は、先にIssueで役割とauthorityを確認してください。

変更は小さく保ち、テストと公開仕様の更新を行い、意味のある単位でコミットしてください。

AIを使ったコントリビューションも歓迎しますが、提出内容の確認・テスト・ライセンス確認はコントリビュータ自身の責任です。
