# flamoris-studio v1.0.4

Assistantの外部モデル送信に対する同意文・チェックボックスを廃止しました。許可されたモデルを選択し、既存の会話開始・モデル切替操作で利用できます。会話履歴・人格snapshot・回答・未送信の質問を保持します。

StudioはAgentの許可モデルを確認し、既存の内部APIに送信許可を渡します。モデル・アカウントの権限、CSRF、未確定処理の保護は維持します。Agentの変更や新しい設定は不要です。旧APIのremoteConsent欄は互換性のため受け付けますが、新規処理の許可はサーバーが決めます。既存の切替記録は元の内部payloadで確認します。

1.0.3から設定・DB・アカウント・接続情報・サムネイル・会話参照を保持して更新できます。DBスキーマ変更・データ移行はありません。amd64/arm64の配布物とUpdaterカタログを公開します。実機の更新は別工程です。

対応はStudio #68のみです。参照画像・ComfyWorkFlow対応のPR #80は含みません。
