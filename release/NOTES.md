# flamoris-studio 1.2.1

Creative action buttons now explain incomplete/invalid settings on click instead of silently disabling. This covers Image, Video, Music generation/transcription, Speech, Raw Intelligence, Assistant send/model selection and personality save. Named feedback preserves drafts and existing input, active/unknown request and permission gates; invalid clicks create no new request identity and never submit or retry. In-flight operations still prevent duplicates, and read-only/frozen updates remain protected. The Image badge now says Service ready, and the internal PHASE 1A header marker is removed. See [action feedback](../docs/ACTION_FEEDBACK.md).

Failed reference-image uploads release their byte reservation after upstream deletion and local cleanup are confirmed, provided no execution references the input. Bounded maintenance also rechecks eligible older revoked uploads; unknown results and retained historical previews stay protected. Image/Video upload errors now distinguish storage quota, busy admission, size/format, incomplete transfer, upstream validation and receipt verification, while preserving drafts and never replaying automatically. Reference reservation defaults increase to 2 GiB and 1,024 rows per user, with aggregate limits of 8 GiB and 4,096 rows. Explicit environment overrides remain unchanged; the 8 MiB per-file limit and existing retention remain. No database migration is required. The original intermittent HTTP 422 still requires live acceptance; this release does not claim that its cause is identified. See [reference-upload recovery](../docs/REFERENCE_UPLOAD_RECOVERY.md).

# flamoris-studio 1.2.0

Connect the dedicated Video editor to Controller / Generation 1.2.1 through the existing authenticated internal HTTP boundary. Choose an owned start image, describe motion, set bounded dimensions/frames/FPS and seed, then track one durable request and retrieve an owned MP4 through the existing player, Assets catalog and download/range endpoints. A distinct end-image field appears only for a matching registered FLF2V definition. Preserve existing accounts, Image/Assistant/Music/Speech behavior, input deletion fences and unknown/no-replay. No database migration or new service credential is required. UI support is distinct from model quality and real Studio/browser acceptance. See [Video operation](../docs/VIDEO_OPERATION.md).
